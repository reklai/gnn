# G&N

G&N is a Go + templ + HTMX website for a local Palau business with five service areas:

- Space Rental
- Cleaning Express
- Construction
- Security
- Bayside Bar

The app is server-rendered, uses a small amount of client-side JavaScript, and keeps all current site content in code.

## Stack

- Go `1.25`
- [`templ`](https://github.com/a-h/templ) for HTML templates
- HTMX for partial page updates
- Vanilla CSS
- Small vanilla JS for the image gallery modal/carousel

## Current Features

- Server-rendered homepage and five service pages
- HTMX rental filtering on `/space-rental`
- Per-card image gallery triggers with a modal carousel
- Mobile navigation
- Versioned static assets
- Cache headers for static assets
- Production-oriented HTTP server timeouts

## Run Locally

Requirements:

- Go `1.25+`
- `templ` CLI if you change `.templ` files

Install `templ`:

```bash
go install github.com/a-h/templ/cmd/templ@latest
```

Start the app:

```bash
go run ./cmd/web
```

Default address:

```text
http://localhost:8080
```

Optional custom address:

```bash
ADDR=:3000 go run ./cmd/web
```

## Development Workflow

If you edit `.templ` files:

## Content Model

All current business copy, phone numbers, service cards, rental data, security details, bar schedule, and placeholder gallery entries live in:

- `internal/content/`

That package is currently the source of truth for the site.

## Gallery Model

Each gallery item uses `PictureSlot`:

```go
type PictureSlot struct {
	Label    string
	ThumbSrc string
	FullSrc  string
	Alt      string
	Caption  string
}
```

Current behavior:

- the card grid uses `ThumbSrc`
- the modal carousel uses `FullSrc`
- if no real image is set yet, the site renders a placeholder tile
- galleries are scoped per card or page-level collection

### Adding Real Images

Put images under `static/images/...` and replace a placeholder entry with real paths.

Example:

```go
Pictures: []PictureSlot{
	{
		ThumbSrc: "/static/images/rentals/studio-1-thumb.jpg",
		FullSrc:  "/static/images/rentals/studio-1.jpg",
		Alt:      "Studio unit living area",
		Caption:  "Studio unit interior",
	},
}
```

If only one image path exists, you can temporarily use the same path for both `ThumbSrc` and `FullSrc`, but separate thumbnail/full-size assets are better for performance.

## Styling and Assets

Static assets are versioned through:

- `internal/components/helpers.go`

That version string is appended to CSS and JS URLs so browser caches update cleanly after changes.

## Performance Notes

The current app is lightweight:

- no database
- no API layer
- no SPA runtime
- low HTML/JS payload

Production-oriented improvements already included:

- `Cache-Control: public, max-age=31536000, immutable` for versioned static assets
- HTTP server timeouts in `cmd/web/main.go`
- thumbnail/full-image split in the gallery model

## Notes

- The purpose of is to be a static based website that is tailored to my current needs
- The site content is currently code-driven, not CMS-driven
- Placeholder images are intentional and can be replaced card by card
- The gallery modal is shared globally, but each trigger only opens the images for its own card
